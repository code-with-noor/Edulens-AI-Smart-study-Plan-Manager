# EduLens - AI Education Platform

## 📖 Introduction
**EduLens** is a smart, AI-powered web application designed to make self-study easier, faster, and more effective for students. By integrating cutting-edge Artificial Intelligence, we provide every student with a "Personal Digital Tutor" that guides them throughout their academic journey.

## 🎯 Problem Statement
- **Time Wasted:** Students often spend too much time searching for notes and creating study schedules instead of actually studying.
- **No Instant Help:** During self-study, teachers or mentors are not always available to clear sudden doubts.
- **Unplanned Study:** Studying without a proper plan during exams often leads to poor time management and bad results.

## 💡 Proposed Solution
EduLens is an all-in-one platform that solves these problems using modern AI. 
- It analyzes what the student needs to study and provides a **Smart Study Plan** with daily tasks.
- It features a **User Dashboard** where students can track their progress.
- It includes a **Doubt Chatbot** allowing students to interact directly with the AI to understand complex concepts.

## ✨ Core Features
1. **Doubt Chatbot:** A 24/7 AI Teacher that answers any academic question.
2. **Smart Study Plan (AI Study Plan Generator):** Generates a daily to-do list showing what is important to study today.
3. **Auto Notes Generator:** Summarizes long and difficult topics into short, easy-to-read notes.
4. **Performance Graph:** Visually tracks the student's progress and completed tasks.
5. **PYQ Analyzer:** Analyzes previous year questions for better exam preparation.
6. **Revision Scheduler:** Automatically schedules revision sessions to ensure better retention.

## 🏗️ System Architecture
- **Frontend (User Interface):** What the user sees and interacts with (built using React & Tailwind CSS).
- **Backend (Server):** Takes the user's request and processes the logic (built using Node.js & Express.js).
- **AI API (OpenRouter):** The 'Brain' of our project that generates the smart responses.
- **Database (MongoDB):** Where user data, plans, and notes are securely saved.

## 💻 Technology Stack
- **Frontend:** React.js, Tailwind CSS, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI Tool:** OpenRouter API / Groq
- **Development Tools:** VS Code, Git, GitHub

## 🚧 Limitations
- **Internet Needed:** The AI features require an active internet connection to work.
- **API Limits:** External API constraints may limit the number of continuous queries.
- **Text Only:** Currently, the AI only understands typed text; it cannot scan images of books or handwritten questions yet.

## 🚀 Future Scope
- **Image Scanning:** Adding a camera feature so students can take a picture of a problem to get the answer.
- **Mobile App:** Converting this web project into a native Mobile App (Android/iOS) for better accessibility.
- **Quiz Mode:** Adding a live MCQ test system for daily practice and self-evaluation.

## 🏁 Conclusion
EduLens acts as a bridge between traditional studying methods and modern AI technology. This project proves that by using AI correctly, we can make the education system much smarter and more student-friendly. In the near future, platforms like this will become a basic necessity for every student.
